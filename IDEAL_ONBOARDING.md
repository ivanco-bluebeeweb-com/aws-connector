# AWS Connector — идеальный первый запуск

Источник: `Docs/session-notes/ONBOARDING_FIRST_LAUNCH_STANDARD.md`.
Целевой пользователь: DevOps-инженер/облачный архитектор, уже
использующий AWS как основную инфраструктурную платформу.

## 1. Credential type

BYOK, максимально высокий риск: Access Key ID + Secret Access Key
(IAM-пользователь) + обязательный default region. Подпись каждого
запроса — Signature Version 4 (SigV4), не статичный токен.

## 2. Идеальный флоу

1. **Первое открытие** — `Empty` с прямой ссылкой "IAM Console > Users >
   Security credentials > Create access key" + явная рекомендация
   ПЕРЕД созданием ключа: "создайте отдельного IAM-пользователя с
   политикой ReadOnlyAccess — этого достаточно для начала работы".
2. **Форма** — Access Key ID + Secret Access Key (оба password-type,
   Secret Access Key никогда не отображается повторно после сохранения)
   + Select региона по умолчанию (us-east-1 и т.д., с коротким
   пояснением "какой регион вы используете чаще всего — это можно
   поменять позже прямо в интерфейсе").
3. **Диагностика при подключении** — вызов `sts:GetCallerIdentity`
   (лёгкий, ничего не читает из инфраструктуры) для проверки валидности
   пары ключей + определения ARN пользователя. Если ключ несёт
   admin/`*:*`-права — мягкое предупреждение ("этот ключ имеет широкие
   права — рекомендуем ограничить его до ReadOnlyAccess"), не блокировка.
4. **После успеха** — сводка "облачного здоровья": количество активных
   EC2-инстансов по регионам, расходы за текущий месяц (Cost Explorer),
   любые Lambda-функции с ошибками за последние 24ч — сразу actionable,
   не просто список сервисов.
5. **Ошибка "SignatureDoesNotMatch"** — конкретное объяснение: "секретный
   ключ введён неверно, либо системное время сильно разошлось" (SigV4
   чувствителен к времени запроса), а не глухая ошибка авторизации.
6. **Ошибка "UnauthorizedOperation" / 403** — отличать от неверных
   ключей: "ключ действителен, но у него нет прав на это действие —
   добавьте нужную IAM-политику" вместо общего "доступ запрещён".
7. **Смена региона** — переключатель региона живёт в самом интерфейсе
   (не только на экране подключения), так как большинство операций
   регионально-специфичны.
